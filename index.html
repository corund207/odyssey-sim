Click the field to add waypoints — the first one is the start. Your path saves automatically.

Shortcuts
  • Drag a point to move it; drag the dot on its arrow to set the heading
  • Double-click a point to switch Point ↔ Pose (Pose controls arrival heading)
  • Arrow keys nudge the selected point (Shift = 2")
  • Delete or right-click removes it; Esc deselects
  • Ctrl+Z / Ctrl+Shift+Z undo and redo
Paste auto code → extract path
